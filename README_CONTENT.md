# Управление контентом сайта «Домиан»

Сайт работает без сборки. Все изменяемые данные находятся в файле `assets/js/content.js`. После правки достаточно сохранить файл и обновить страницу.

## Документы

1. Подготовьте документ в формате PDF.
2. Назовите файл латиницей, строчными буквами, без пробелов. Например: `franchise-agreement.pdf`.
3. Загрузите файл в папку `assets/docs/`.
4. Найдите нужную карточку в массиве `documents` файла `assets/js/content.js`.
5. Укажите относительный путь в поле `file`:

```js
{
  title: "Франшизный договор",
  description: "Условия сотрудничества, права и обязанности сторон",
  file: "assets/docs/franchise-agreement.pdf"
}
```

После этого кнопка карточки автоматически получит текст «Открыть документ» и откроет PDF в новой вкладке. Если поле `file` пустое, кнопка ведёт к финальному блоку обращения.

Для публикации рекомендуется PDF с встроенными шрифтами и размером до 10 МБ. Перед загрузкой проверьте читаемость текста на телефоне.

## Фотографии и галереи

Папки для изображений:

- `assets/images/certificates/` — сертификаты и грамоты;
- `assets/images/awards/` — награды;
- `assets/images/offices/` — офисы;
- `assets/images/events/` — брокер-туры, обучение, форумы и корпоративные мероприятия;
- `assets/images/partners/` — логотипы партнёров и застройщиков.

Для фотографий используйте WebP или JPEG. PNG подходит для материалов с прозрачностью, SVG — для официальных логотипов. Рекомендуемые параметры:

- фотографии офисов и событий: 1600 × 1000 px или больше, соотношение сторон около 16:10;
- сертификаты и грамоты: от 1400 px по короткой стороне, вертикальная ориентация;
- награды: от 1400 × 1000 px;
- логотипы партнёров: SVG либо PNG с прозрачным фоном, ширина от 800 px;
- размер одного растрового файла: желательно до 800 КБ.

Имена файлов лучше задавать латиницей, без пробелов: `office-rostov-01.webp`, `broker-tour-2026-03.webp`.

### Добавление сертификата

Загрузите изображение в `assets/images/certificates/`, затем добавьте объект в `galleries.certificates.items`:

```js
{
  src: "assets/images/certificates/certificate-01.webp",
  alt: "Сертификат Домиан",
  caption: "Название сертификата, год"
}
```

### Добавление грамоты

Загрузите изображение в `assets/images/certificates/`, затем добавьте объект в `galleries.diplomas.items`:

```js
{
  src: "assets/images/certificates/diploma-01.webp",
  alt: "Грамота Домиан",
  caption: "Название грамоты, год"
}
```

### Добавление фотографий

Выберите подходящий массив:

- `galleries.offices.items` — офисы;
- `galleries.brokerTours.items` — брокер-туры;
- `galleries.training.items` — обучение;
- `galleries.forums.items` — форумы;
- `galleries.corporateEvents.items` — корпоративные мероприятия;
- `galleries.awards.items` — награды.

Пример:

```js
{
  src: "assets/images/events/training-2026-01.webp",
  alt: "Обучение агентов Домиан",
  caption: "Практическое обучение команды"
}
```

Поле `alt` должно кратко описывать изображение для посетителей, использующих экранный диктор. В `caption` указывается подпись для галереи и полноэкранного просмотра.

Если нужен отдельный облегчённый файл для сетки, добавьте поле `thumb`, а в `src` оставьте полноразмерное изображение:

```js
{
  src: "assets/images/events/forum-2026-full.webp",
  thumb: "assets/images/events/forum-2026-preview.webp",
  alt: "Форум собственников Домиан",
  caption: "Квартальный форум сети"
}
```

Пустая категория не выводится на странице. Добавленная категория появляется автоматически. Все галереи поддерживают полноэкранный просмотр, клавиши Esc, ← и →, а также сенсорные экраны.

## Партнёры и застройщики

Добавляйте только официальные материалы компаний, с которыми подтверждено сотрудничество.

1. Загрузите логотип в `assets/images/partners/`.
2. Добавьте объект в массив `partners`:

```js
partners: [
  {
    name: "Название компании",
    logo: "assets/images/partners/company-name.svg",
    alt: "Логотип компании",
    caption: "Партнёр Домиан"
  }
]
```

Логотип появится в галерее «Партнёры и застройщики». Не добавляйте одну и ту же компанию одновременно в `partners` и `galleries.partners.items`.

## Контакты

Контакты задаются в объекте `contacts`:

```js
contacts: {
  phone: "+7 000 000-00-00",
  email: "mail@example.ru",
  telegram: "domian_name",
  whatsapp: "+70000000000",
  formEndpoint: ""
}
```

Оставляйте поле пустым, если канал связи не используется: соответствующая кнопка не появится.

### Телефон

Укажите номер в поле `phone` в международном формате. Отображение можно оформить пробелами и дефисами — ссылка для звонка сформируется автоматически.

### Telegram

В поле `telegram` можно указать имя без символа `@`, имя с `@` или полный адрес `https://t.me/...`.

### WhatsApp

В поле `whatsapp` можно указать номер в международном формате или полный адрес `https://wa.me/...`.

### Email

Укажите рабочий адрес в поле `email`. Сайт автоматически создаст ссылку для нового письма.

## Подключение формы

Форма отображается только при заполненном `contacts.formEndpoint`. Нужен HTTPS-адрес обработчика, который принимает POST-запрос с полями:

- `name` — имя посетителя;
- `phone` — телефон посетителя.

Пример:

```js
contacts: {
  phone: "+7 000 000-00-00",
  email: "office@example.ru",
  telegram: "domian_name",
  whatsapp: "+70000000000",
  formEndpoint: "https://example.ru/api/franchise-request"
}
```

До публикации формы проверьте отправку тестового обращения, уведомление ответственного сотрудника, защиту от нежелательных отправок и требования к обработке персональных данных. Если endpoint не указан, форма не создаётся.

## Социальные сети

Ссылки в подвале управляются объектом `socialLinks`:

```js
socialLinks: {
  vk: "https://vk.com/example",
  youtube: "",
  rutube: "",
  dzen: ""
}
```

Пустые ссылки не отображаются.

## Основные цифры, условия и города

- `heroMetrics` — показатели первого экрана;
- `networkMetrics` — карточки масштаба сети;
- `turnover` — совокупный комиссионный оборот;
- `economy` — диапазоны и три сценария офиса;
- `conditions` — карточки условий;
- `cities` — список городов в разделе сети.

При обновлении чисел меняйте одновременно числовое поле `value` и готовую строку `display`, если она присутствует.

## Публикация на GitHub Pages

Разместите содержимое этой папки в корне репозитория. В настройках GitHub Pages выберите публикацию из корня основной ветки. Все пути на сайте относительные, поэтому дополнительных настроек и сборки не требуется.

Перед публикацией откройте `index.html` через локальный веб-сервер и проверьте страницу на компьютере и телефоне.
